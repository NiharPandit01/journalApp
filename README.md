# Journal App (Spring Boot Backend)

## 📌 Overview
This is a Spring Boot backend project that provides REST APIs for a journal application with features like user management, scheduling, email notifications, and external API integrations.

---

## 🚀 Features
- User and Journal Entry management (CRUD APIs)
- Email notifications system
- Weather API integration
- Quotes API integration
- Text-to-Speech feature
- Scheduled background tasks
- Unit testing with JUnit
- CI/CD pipeline using GitHub Actions

---

## 🛠️ Tech Stack
- Java
- Spring Boot
- Maven
- MongoDB / MySQL (based on your setup)
- Git & GitHub
- GitHub Actions
